# PMTCONCON Studio 0.3.0-alpha.4 릴리스 노트

0.3.0-alpha.4는 Gemini 요청 오류와 Windows 파일 끌기 오류를 고치고, AI 생성 참고 이미지와 GIF 수동 웹 편집 흐름을 보강한 Windows 프리릴리스입니다.

## Gemini 요청 진단

- Gemini 2.5 Flash Image에는 지원하지 않는 `image_size`를 보내지 않고, Gemini 3.1 Flash Image에만 `1K`를 요청합니다.
- Interactions 응답의 모든 모델 출력 단계에서 최종 JPEG를 찾아 후보로 가져옵니다.
- HTTP 400 응답은 안전한 필드 이름만 보여 주며 공급자 응답 본문이나 API 키를 노출하지 않습니다.
- 잘못된 API 키와 무료 등급/결제 조건 문제를 요청 형식 오류와 구분해 다음 행동을 안내합니다.
- 자동 재시도, 자동 공급자 전환과 숨은 과금 요청은 하지 않습니다.

Gemini 이미지 API 모델은 현재 무료 등급이 없습니다. 비용을 원치 않으면 API 대신 Gemini AI Studio 웹 전달을 열고, 사용 전 현재 계정·모델에 과금 표시가 없는지 확인하세요.

## Windows 파일 끌기

- AppData 경로와 Windows 정규 경로(`\\?\` 형태)가 다르게 표현되어 관리 파일을 잘못 거부하던 문제를 수정했습니다.
- 실제 관리 루트 밖 경로, 사라진 파일, 디렉터리, symlink/reparse 하위 경로와 변조된 파일은 계속 거부합니다.
- 네이티브 끌기가 맞지 않는 환경에서는 기존 Explorer 선택 방식을 그대로 사용할 수 있습니다.

## AI 결과 크기 처리

- AI가 200×200 대신 1024×1024처럼 같은 종횡비로 반환하면 원본 결과 파일을 그대로 보존합니다.
- 결과 검토에는 크기 정규화 경고를 표시하고, 적용/내보내기 단계에서 목표 셀 크기로 로컬 변환합니다.
- 종횡비가 다르거나 필요한 투명도가 사라진 결과는 계속 차단합니다.

## 생성 참고 이미지

- `AI 아이콘 만들기`에서 현재 모음의 단일 아이콘과 외부 PNG/JPG/GIF를 합쳐 1–16개까지 참고 자료로 선택할 수 있습니다.
- 외부 파일은 합계 16MB, 전체 참고 소스는 누적 1.28억 픽셀로 제한합니다.
- 비정사각형 아이콘은 늘이지 않고 비율을 유지해 배치하며, GIF는 첫 프레임 포스터를 사용합니다.
- reference board는 출력 그리드가 아니라 캐릭터·그림체 참고 자료임을 프롬프트와 화면에서 분리합니다.
- 준비된 reference board는 `최근 AI 전달`에서도 다시 끌기, Explorer 열기와 요청 취소를 할 수 있습니다.

## GIF 수동 웹 AI

- GIF 편집기의 `GIF AI 프레임 시트 작업 시작`에서 모든 프레임을 clean PNG 시트와 manifest로 내보냅니다.
- 프레임 순서, 셀 geometry, 투명도, 캐릭터·스타일 일관성과 timing/loop 복원을 요구하는 기본 프롬프트를 만듭니다.
- Gemini AI Studio 또는 NovelAI 공식 웹을 연 뒤 수정 PNG를 다시 가져올 수 있습니다.
- 결과는 별도 GIF 처리 버전으로 만들며 원본 GIF, 프레임별 delay와 loop 설정을 보존합니다.

직접 GIF API 호출, 웹 로그인/DOM 제어, 자동 파일 첨부, 생성 완료 감지와 자동 다운로드는 포함하지 않습니다.
