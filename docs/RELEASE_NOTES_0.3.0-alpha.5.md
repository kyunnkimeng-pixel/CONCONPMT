# PMTCONCON Studio 0.3.0-alpha.5 릴리스 노트

0.3.0-alpha.5는 GIF 프레임 시트를 웹 AI로 전달하고 다시 가져오는 흐름을 단순화하고,
투명 배경·불투명 결과·가짜 체커무늬를 사용자가 안전하게 검토할 수 있도록 보강한
Windows 프리릴리스입니다.

## GIF 웹 AI 전달

- 웹 AI에는 라벨과 격자가 없는 `frames_sheet_*.png`만 올리도록 파일 역할을 분리했습니다.
- `frames_guide_*.png`는 사람 확인용, manifest는 앱 복원용으로 표시하며 웹 업로드 동작을 제공하지 않습니다.
- 같은 작업 창에서는 manifest와 페이지 순서를 앱이 기억하므로 결과 페이지만 다시 넣으면 됩니다.
- 앱을 닫은 뒤 예전 작업을 복구할 때만 수동 manifest 선택을 사용합니다.
- 각 clean page를 Windows 네이티브 파일 끌기로 전달하거나 Explorer에서 바로 찾을 수 있습니다.
- 사용자 지정 출력 폴더의 페이지도 검증 후 앱 관리 경로에 staging하여 안전 경로 오류를 줄였습니다.

## GIF 결과 가져오기

- PNG뿐 아니라 JPG/JPEG와 정적 WebP를 실제 파일 형식으로 판별해 가져옵니다.
- 여러 페이지는 manifest의 page slot에 명시적으로 연결하므로 브라우저가 파일명을 바꿔도 대응할 수 있습니다.
- animated WebP는 첫 프레임으로 조용히 바꾸지 않고 지원하지 않는 결과로 차단합니다.
- 원본 GIF는 변경하지 않고 새 처리 버전을 만들며 프레임 순서, delay와 loop 설정을 복원합니다.

## 투명 배경과 가짜 체커 검토

- 원본 없는 단일/그리드 생성은 투명 배경을 기본으로 권장합니다.
- JPG나 불투명 PNG/WebP는 사용자가 `배경 포함 결과 허용`을 명시적으로 선택해야 합니다.
- 고신뢰도 회색 체커무늬는 투명 필수 모드에서 차단하며, 배경 포함 모드에서는 경고와 실제 미리보기를 보여 줍니다.
- 자동 배경 제거로 외곽선과 안티앨리어싱을 손상시키지 않습니다.
- 최종 아이콘 생성 전 결과를 크게 다시 확인해야 하며, 불투명 허용 동의는 다음 작업으로 넘어가지 않습니다.

## Gemini와 NovelAI 안내

- 투명 원본은 JPEG만 반환하는 현재 Gemini 직접 이미지 API로 보내기 전에 차단하여 alpha 손실과 비용 발생을 피합니다.
- Gemini AI Studio 웹 전달에는 수정 범위, 셀 배치, 캐릭터와 그림체 유지 요구를 강화했습니다.
- NovelAI는 Prompt와 Undesired Content를 분리하고 Image2Image, Vibe Transfer와 Precise Reference의 용도를 구분해 안내합니다.
- 배경 포함 모드에서는 NovelAI Prompt와 Undesired Content가 서로 모순되지 않도록 조정했습니다.
- NovelAI가 200×200 대신 192×192 등 지원 크기로 바꾸더라도 정사각 비율을 검증한 뒤 앱에서 목표 크기로 정규화할 수 있습니다.

## 알려진 제한

- 생성형 공급자는 원본 그림체, 캐릭터 세부와 여러 GIF 프레임의 시간적 일관성을 완전히 보장하지 않습니다. 최종 미리보기를 확인하세요.
- 웹 로그인, DOM 제어, 생성 완료 감지와 자동 다운로드는 포함하지 않습니다.
- 설치 파일은 서명되지 않은 NSIS 프리릴리스이므로 Windows에서 알 수 없는 게시자 경고가 나타날 수 있습니다.
- prerelease 버전 문자열 제약 때문에 MSI는 제공하지 않습니다.
