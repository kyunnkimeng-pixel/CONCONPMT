# PMTCONCON Studio 0.3.0-alpha.3 릴리스 노트

0.3.0-alpha.3은 여러 아이콘을 한 번에 AI 웹 작업으로 왕복하고, GIF 프레임
스프라이트의 시간 정보를 안전하게 복원하며, 임시 전달 파일을 앱 안에서 관리하는
Windows 프리릴리스입니다.

## AI 그리드 일괄 편집

- 정적 단일 아이콘 2–16개를 선택해 한 장의 투명 그리드로 준비할 수 있습니다.
- 선택 순서, 셀 위치, 투명 여백과 한 셀당 한 아이콘 규칙이 기본 프롬프트에
  자동으로 포함됩니다.
- 웹에서 받은 결과는 전체 시트와 각 셀을 검토한 뒤에만 저장됩니다.
- 기존 아이콘 편집 결과는 전부 함께 비활성 후보로 저장하거나 전부 저장하지
  않습니다. 원본과 현재 적용 이미지는 자동으로 바뀌지 않습니다.
- 빈 셀이나 확인되지 않은 구조 오류가 있으면 저장을 막고 교정 프롬프트를
  제공합니다.

## 원본 없는 아이콘 생성

- 기존 원본 없이 단일 아이콘 또는 최대 16개의 그리드 아이콘을 생성할 수
  있습니다.
- 결과 검토가 끝나기 전에는 가짜 빈 아이콘이나 원본 행을 만들지 않습니다.
- 최종 저장은 아이콘, 조각, crop, 순서와 출처 정보를 한 트랜잭션에서 모두
  만들거나 아무것도 만들지 않습니다.

## GIF 프레임 스프라이트 왕복

- GIF의 모든 프레임을 작업 시트와 manifest로 내보내고, 수정된 시트를 새 GIF
  variant로 다시 가져올 수 있습니다.
- manifest의 페이지 파일명, 프레임 순서와 프레임별 delay를 검증합니다.
- 원본 반복, 무한 반복, 한 번 재생과 지정 횟수 반복을 복원합니다.
- 출력 크기와 디코딩 작업량을 제한하며 원본 GIF는 보존합니다.

## 브라우저 전달

- Windows에서는 PMTCONCON Studio가 다시 검증한 관리형 입력 파일을 공식 웹의
  업로드 영역으로 직접 끌 수 있습니다.
- 키보드, 비Windows 환경 또는 호환성 문제가 있을 때는 Explorer에서 파일을
  선택하는 안정적인 대체 경로를 제공합니다.
- 프롬프트 복사와 공식 웹 열기를 한 흐름으로 연결했습니다.

브라우저 로그인, DOM, 쿠키, 다운로드와 생성 완료는 자동 제어하지 않습니다.
확장 프로그램이나 로그인 정보 저장도 요구하지 않습니다.

## 임시 전달 파일 관리

- 앱을 켜 둔 동안 15분마다 만료 정리와 실패한 정리를 다시 시도합니다.
- 단일 아이콘과 그리드 전달 파일을 합쳐 256MiB 한도를 적용합니다.
- 진행 중인 작업은 자동 삭제하지 않고, 완료·취소·만료된 payload부터
  정리합니다.
- 사이드바 `최근 AI 전달`에서 저장 공간, 전달 상태, 만료 시각, 정리 지연과
  최근 기록을 확인하고 파일을 다시 끌거나 Explorer에서 열 수 있습니다.
- payload가 정리된 뒤에도 안전한 이력 행은 남습니다.

## AI 서비스 범위

기본 흐름은 토큰과 유료 API 없이 Gemini 또는 NovelAI 공식 웹을 사용합니다.
실제 유료 API 호출은 이 릴리스의 완료 조건에 포함하지 않았으며, 사용자 동의
없는 자동 재시도·공급자 전환·과금 요청은 수행하지 않습니다.
