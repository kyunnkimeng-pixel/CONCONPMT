# PMTCONCON Studio 0.3.0-alpha.2 릴리스 노트

0.3.0-alpha.2는 0.3.0-alpha.1의 이미지 표시 회귀를 수정하는 Windows 핫픽스입니다.

## 수정 사항

- Tauri asset protocol의 앱 데이터 범위를 올바른 `$APPDATA/**`로 복원했습니다.
- 가져온 이미지, GIF, 모음 커버, 썸네일과 편집기 미리보기가 다시 표시됩니다.
- `$APPDATA` 뒤에 앱 식별자를 중복해 붙이는 설정이 다시 들어오지 않도록 자동 회귀 테스트를 추가했습니다.

## 데이터 안전성

- 0.3.0-alpha.1에서 가져온 원본과 썸네일은 삭제되거나 손상되지 않았습니다.
- 기존 `library.sqlite`와 앱 라이브러리를 그대로 사용하므로 재업로드할 필요가 없습니다.
- 0.3.0-alpha.1 설치 위에 0.3.0-alpha.2를 설치하면 됩니다.

## 검증

- 실제 사용자 AppData의 원본 84개와 활성 아이콘 25개의 파일 존재·해시·이미지 디코딩을 확인했습니다.
- 수정된 release 실행 파일에서 모음 커버와 아이콘 그리드가 정상 렌더링되는 것을 확인했습니다.
- 프런트엔드 테스트 271개와 Rust 테스트 252개를 통과했습니다.
